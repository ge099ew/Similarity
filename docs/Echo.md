# Echo（project.eho）

EchoはSimilarity独自の安全性レポートシステムです。
コンパイル時にプロジェクト全体をスキャンし、`Mem[risk{}]` ブロックを検出・記録します。

---

## 出力例

```
╔══════════════════════════════════════════╗
║        ⚠️   RISK BLOCK DETECTED  ⚠️        ║
╚══════════════════════════════════════════╝

  [1] main.iia : line 20-21
      → deref use

コンパイルを続行しますか？ [Y/n]:
```

---

## 仕様

- コンパイルのたびに `project.eho` を上書き生成
- riskが0件でも生成
- `--ir-only` モードではスキップ
- riskブロックを `[1][2][3]` と通し番号で列挙

---

## 設計思想

unsafeな操作を暗黙に許可するのではなく、
**全てのunsafe操作を明示・記録**することでSimilarityは安全性を担保します。
